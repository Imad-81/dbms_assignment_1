# Project Archive (Historical & Working Deliverables)

This directory contains historical documentation, slide generation HTML sources, legacy submission packages, and raw SQL files retained for internal reference:

- `archive/docs/` — Conceptual notes, viva guides, and initial design notes.
- `archive/html/` — Presentation deck HTML source templates and ERD interactive viewer.
- `archive/submissions/` — Previous milestone submission packages and outputs.
- `archive/sql/` — Raw PostgreSQL DDL and seed files (also mirrored in `web/prisma` and test runners).

> **Note for Evaluators:** The active, required submission materials are structured in:
> - `Presentation-I/`
> - `Presentation-II/`
> - `Presentation-III/`
> - `Project-Report/`
> - `web/`
